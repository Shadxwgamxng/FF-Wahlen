# Testdaten

`overpass-ostholstein-sued.json` enthält echte OpenStreetMap-Daten aus dem Kreis Ostholstein (Ausschnitt), im Format einer Overpass-API-Antwort. Der Browser-Test nutzt sie, um die Overpass-Abfragen offline und reproduzierbar zu beantworten.

- Quelle: OpenStreetMap über den BBBike-Extrakt „Luebeck“, gefiltert auf die Kreisgrenze Ostholstein, Adressen auf 2.500 ausgedünnt.
