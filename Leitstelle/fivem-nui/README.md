# LEITWARTE – Leitplatz-Overlay für FiveM

NUI-Overlay des Leitplatzes (Notrufe, Einsätze, Einsatzmaske, Wachentableau, Funk) in den Stilen „Klassisch“ und „Modern“.

- `ANLEITUNG-FUER-CLAUDE.md` – Text für den Chat, der das Overlay in das FiveM-Script einbaut
- `SCHNITTSTELLE.md` – Datenformat und Callbacks
- `STYLEGUIDE.md` – Gestaltung
- `html/` – das Overlay (ohne Build-Schritt); Vorschau: `html/index.html` im Browser öffnen
- `beispiel/` – QBCore-Vorlage (fxmanifest, client, server)
- `bilder/` – Screenshots
